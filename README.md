Repositorio escaparate oficial de **Atomic UI (`@atomic-ui/core`)**, sistema de diseño corporativo gobernado sobre **Angular 22**, **Signals** y arquitectura atómica (átomos, moléculas, organismos, superficies y plantillas estructurales Chasis A, B y C) del ecosistema **Artifact Barracuda**.

> **Nota de propiedad intelectual y distribución:** Este repositorio público aloja exclusivamente la documentación ejecutiva y la distribución estática minificada para GitHub Pages (sin mapas de origen ni código fuente embebido en Compodoc). El código fuente y las herramientas de gobernanza residen en bóveda privada (`archware/atomic-ui-core` y Azure DevOps).

## Pilares arquitectónicos del sistema de diseño

- **Arquitectura atómica reactiva con Angular Signals:** Componentes standalone con detección de cambios `OnPush`, entradas reactivas y cero dependencias de hojas de estilo ad-hoc en aplicaciones consumidoras.
- **Sistema de tokens semánticos multi-tema:** Gobernanza visual mediante variables CSS semánticas con soporte nativo para modo claro, modo oscuro y paletas de marca, verificadas por compuertas de contraste WCAG AA.
- **Gobernanza criptográfica de consumidores:** Verificación determinista de procedencia mediante huellas SHA-256 canónicas sobre componentes y servicios compartidos entre aplicaciones web y clientes de escritorio (Tauri, Wails y PyWebView).
